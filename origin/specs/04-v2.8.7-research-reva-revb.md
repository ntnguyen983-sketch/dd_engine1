# v2.8.7+ — Research, Rev.A and Rev.B lineage

## Why this layer exists

v2.8.7+ is explicitly a research layer above the v2.8.6 Frozen Core. Parameters or formulas that have not been empirically established are hypotheses and require an explicit version/calibration status.

## Rev.A

Rev.A reconciles Frozen Core v2.8.6 with the 2.8.7 research layer and runtime continuity. Its central constraints are:

- Frozen Core identity, validation, canonical state, structural operators and invariants cannot be mutated by research code.
- Research parameters may run as hypotheses but must carry labels/version/calibration status.
- Observation continues the active case as evidence/context; it does not reinitialize the root snapshot unless a valid initialization event occurs.
- Forward-only means new evidence affects a later tick, not the already locked state.
- The same canonical input + research profile + runtime policy must produce the same result.
- Semantic data is kept out of the computational core until the permitted decoding/interpretation layer.

## Rev.B unified authority

Rev.B reconciles Rev.A and the full specification into one runtime authority. It explicitly separates:

- Master Runtime / canonical runtime rules;
- Frozen Core lineage;
- Research/BEC layer;
- Knowledge Layer for Chu Dịch/Lục Hào adapters;
- Decoder/Inference layer;
- Evidence/Observer runtime.

Research/BEC does not automatically become Core-validated. Knowledge supplied through an adapter cannot mutate Core State. Evidence creates a future transition rather than retroactively changing the past.

## Calibration rule

Quantitative outputs require precision and calibration status. Prediction error becomes calibration evidence for future profiles; it is not a reason to rewrite an already issued historical result.

## Architectural lesson carried into v3.4

The most important inheritance is not any particular BEC formula. It is the boundary discipline: known quantities are computed; unknown/unvalidated quantities remain unknown. A reference implementation must never invent a formula merely to fill an output field.
