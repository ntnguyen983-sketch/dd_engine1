# DUYÊN DỊCH — 3A v3.4 CURRENT ARCHITECTURAL ANCHOR

## Purpose

3A is a Dynamic Execution Layer over the same Duyên Dịch world. It is not a second ontology competing with v3.0 and not an independent “thing finder”.

## Representation basis

The final expressive basis is:

`Định danh | Định lượng | Định tính`

### Định danh
Reference handles for observation streams: entity, space, event, relation, case and other computational references. The identifier does not assert permanent selfhood or intrinsic essence.

### Định lượng
Observed or explicitly supplied quantities in space-time: coordinates, timestamps, magnitudes, inflow/outflow, bottleneck, intervals, recurrence, uncertainty, topology counts and other closed measurements.

### Định tính
Observed patterns derived from quantities and evidence: convergence, divergence, recurrence, rhythmicity, irregularity, transition, density and similar descriptions. A quality label must remain traceable to the quantities/evidence that support it.

## Core objects

- `N_i`: reference to an entity/actor/phenomenon stream.
- `O_{i,k}`: observation of that stream at time `t_k` and spatial node `V_k`.
- `I_m`: directed interaction event with relation, direction, magnitude and timestamp.
- `V_k`: spatial node/topological location.
- `B(V_k)`: spatial bottleneck computed from the node's incoming and outgoing flow.
- `t_k`: temporal reference.
- `STATE(t)`: measured/derived state at a time, with transitions treated conditionally.

## Spatial bottleneck

`B(V_k)` belongs to space. It is not an intrinsic force label of `N_i` merely because `N_i` occupies or crosses `V_k`.

Flow roles must be explicit:

- `flow_role = IN` contributes to `F_in(V_k)`;
- `flow_role = OUT` contributes to `F_out(V_k)`.

Then the node-level bottleneck is the difference between accumulated incoming and outgoing flow.

## Three independent counts

### event_count
Number of interaction events involving the referenced entity in the observation window.

### cycle_count
Number of directed closed topology cycles in the graph in which the node participates.

### K_rep
Number of repetitions of a specified temporal interaction motif. It is not interchangeable with graph cycle count.

## Rhythm

For a relation sequence `(source, target, relation)`, timestamps are ordered and converted with timezone-aware ISO-8601 parsing. Inter-event intervals are measured on that sequence. `σ_rhythm` describes dispersion of those intervals.

A flat list of all timestamps for an entity is not an adequate substitute for relation-level event sequence analysis.

## Candidate ranking

Where a candidate-ranking contract is explicitly part of the implementation profile, preserve the declared multi-level ordering and deterministic tie-break. Do not introduce a new ranking criterion merely because an implementation needs one.

## Calibration boundary

No implementation may invent values for unavailable dynamic/calibration quantities. In particular, values such as BEC-derived state, net-output state, transition state or S07 classification must be sourced from a closed canonical formula and its required inputs. Otherwise return `None`, an unavailable status, or an explicit calibration-required state.

## Relation to v3.0

v3.0 supplies structural context: quẻ/hào, elemental/reference operators, spatial/topological mapping and other structural encodings.

3A supplies dynamic observation: events, flow, rhythm, recurrence, spatial accumulation and transitions.

They meet at the observed state, not by allowing one layer to overwrite the other.

## Ground truth / L4

Ground truth is an external observational comparison. L4 calibration may update declared research/calibration parameters according to its own contract, but it must not retroactively rewrite historical observations or pretend that a calibrated hypothesis was an original axiom.

## Implementation status

This file is an architectural anchor, not a claim that every historical equation is already fully implemented. Production branches must derive their executable contracts from the Origin and carry explicit provenance.
