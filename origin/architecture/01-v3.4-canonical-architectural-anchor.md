# DD-3A v3.4 — CANONICAL ARCHITECTURAL ANCHOR

Identifier: `DD-3A-v3.4-CANONICAL-ARCHITECTURAL-ANCHOR`

## Status

Permanent architectural anchor. The lock applies to the architecture/ontology/reference frame, not to every implementation detail and not to a claim that the world itself is permanent.

## Core principle

Duyên Dịch does not model a fixed object or fixed truth. It models observed existence, location, time, state and interaction within an open system; from sequences of interaction it describes dynamics, rhythm, repetition and state transition.

## Three modes of expression

### 1. Định danh — ID

A reference symbol used to distinguish an observation stream (`N_i`, `V_k`, `I_m`, etc.). It is not an assertion of self, essence or permanent identity.

### 2. Định lượng — Quantity

Measured quantities in space/time and interaction: coordinates, timestamps, force, flow, bottleneck, intervals, counts, rhythm deviation and other explicitly defined numerical observations.

### 3. Định tính — Quality

Observed patterns of movement or configuration derived from quantitative data and evidence. Quality is descriptive, not inherently a moral/value judgment.

## N(n) ontology

The general world model is an open set of observation references:

`N = {N1, N2, ..., Nn}` with n extensible.

Core records include:

- `Entity / N_i` — reference to an observed phenomenon/actor;
- `Observation O_{i,k}` — observation at time `t_k` and space `V_k`;
- `Interaction I_m` — directed event between references at time `t_m`;
- `Space V_k` — spatial/topological reference;
- `Time t_k` — temporal reference;
- `State(t)` — current observed configuration, not permanent essence.

## v3.0 ↔ 3A

- **v3.0 Structural Domain**: structural reference, quẻ/hào mapping, elemental/structural operators, topology.
- **3A Dynamic Execution Layer**: event sequences, flow/force, spatial bottleneck, rhythm/repetition, transitions and calibration.

3A is not a second ontology standing beside v3.0. Both operate on the same N(n) world model.

## Entity vs Space

A spatial bottleneck belongs to a spatial node, not automatically to the entity occupying or traversing it.

`B(V_k) = F_in(V_k) - F_out(V_k)`

Therefore an observed object at `V_k` may be associated with a bottleneck at `V_k`, but the bottleneck is not a property of the object's supposed essence.

## Three independent counts

- `event_count`: number of interaction events involving the reference in the observation window.
- `cycle_count`: number of directed closed cycles in the interaction topology involving the reference.
- `K_rep`: number of repetitions of a specific interaction motif through time.

These must never be collapsed into one variable.

## Rhythm

For repeated occurrences of the same directed relation motif, use its event sequence and time intervals. `sigma_rhythm` describes dispersion of those intervals. It is a property of the observed sequence, not an intrinsic property of a thing.

## Calibration boundary

If a dynamic quantity depends on an L4 calibrator or Ground Truth and the required calibrated state is absent, the engine must return an explicit unknown/None/uncomputed state. It must not invent a proxy formula and label it canonical.

## Implementation boundary

Flexible: programming language, database, API, UI, graph parser, solver optimization, adapters, deployment and storage.

Anchored: N(n) reference model, ID/Quantity/Quality expression, Entity/Space distinction, topology vs temporal repetition, forward-only calibration boundary and provenance discipline.
