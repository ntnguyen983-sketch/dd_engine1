# DUYÊN DỊCH — ORIGIN ARCHIVE MAP

Branch role: `chinh-ly-origin-taxonomy`

This archive is the source-of-truth preparation layer for reconstructing the complete Duyên Dịch lineage. It is not itself a runtime implementation. Its job is to preserve origin, evolution, equations, experiments, implementation evidence, contradictions and the current architectural anchor without collapsing unlike things into one rule set.

## 4. Preservation rule

A later document may supersede an earlier rule for implementation, but the earlier rule remains archived. “Origin complete” therefore means the complete intellectual and technical lineage is recoverable, not that every historical formula is still executable.
