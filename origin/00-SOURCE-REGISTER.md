## Reconciliation rule

Duplicate documents are not treated as separate authorities. They are evidence for lineage. Where versions conflict, the archive must preserve the conflict/history and explicitly identify the later reconciled rule; it must not silently erase the earlier text.

## Completion criterion

The origin is considered content-complete only when every materially different conceptual/technical contribution in the registered source set has either:

1. been preserved verbatim as a source artifact where feasible; or
2. been incorporated into a consolidated lineage document with explicit provenance and no loss of a materially different rule, definition, boundary, formula or design decision.

Only after this condition is met should implementation branches be treated as derived builds.
