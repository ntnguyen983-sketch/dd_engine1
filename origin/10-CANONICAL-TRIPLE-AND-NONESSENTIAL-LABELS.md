# DD ORIGIN — Canonical Representational Triple

## Final direction

The project should not confuse a useful label with an underlying essence. Because observations are conditional and phenomena change, labels are references, not permanent ontological claims.

The stable representational contract is therefore:

> **Định danh | Định lượng | Định tính**

## 1. Định danh

A reference key that lets the system distinguish an observation stream, spatial node, event or other record. An identifier does not assert selfhood, permanence or intrinsic nature.

Examples: `N1`, `V3`, `I-05`, an evidence reference, or an adapter-level external id.

## 2. Định lượng

Measured or computed quantities anchored to a time/space context and their provenance. Examples include timestamp, coordinates, magnitude, flow in/out, bottleneck, interval, repetition count, cycle count, rhythm deviation and uncertainty.

## 3. Định tính

A description of an observed pattern arising from quantitative values and evidence. It may describe convergence, divergence, repetition, irregularity, accumulation, transition or other model-defined patterns. It must not smuggle in an unsupported value judgment or pretend to be an immutable essence.

## 4. What is deliberately removed

The current anchor does not require permanent labels such as 'good/bad', 'auspicious/inauspicious', 'fixed actor essence' or any other identity claim merely because a historical layer used them.

Historical labels remain available as source material and decoder vocabulary. They are not automatically part of the computational core.

## 5. Relationship to v3.0 and 3A

v3.0 contributes structural reference data and transformations. 3A contributes dynamic observation of interactions, space, flow and rhythm. Both feed the same representational triple.

## 6. Practical consequence

A future implementation may add a new entity type, relation, data source, visual label or decoder without changing the triple. If a new mathematical quantity is introduced, it belongs to the quantitative layer; if a new pattern is derived, it belongs to the qualitative layer; if a new reference key is needed, it belongs to identification.

This is the architectural anchor, not a claim that any current snapshot of the world is permanent.
