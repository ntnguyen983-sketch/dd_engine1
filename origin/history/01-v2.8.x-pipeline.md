# Duyên Dịch v2.8.x — pipeline và freeze

Tầng v2.8.x hình thành một pipeline máy thực thi rõ ràng: Raw Input → Normalize/SL-COL → Structural Decode → Topology/DPKE → Rigid Checks → DWL → Force Solver → Field Solver → Firewall → Emergence → Spacetime/Calibration → Canonical JSON + SHA-256.

Các tài liệu v2.8.x cũng xác lập nguyên tắc Frozen Core: lõi không bị sửa chỉ vì một ca riêng lẻ; Runtime, Adapter, Plugin, API và SDK có thể mở rộng. Bản Rev.A phân biệt Frozen Core với Research Layer và yêu cầu deterministic/forward-only khi một profile thực thi đã được cố định.

Trong quá trình chỉnh lý, các công thức chưa đủ cơ sở không được tự động nâng thành canonical. Đây là tiền đề để sau này tách Reference Implementation, Calibration và Production Engine.
